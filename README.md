# Introduction
Virtualdelay is a tool to delay audio from an internal or external
input source. It is particulary useful in live broadcasting to create a few seconds of separation between a live event and the transmission to the audience. This delay allows producers to censor inappropriate content—such as swearing, profanity, or wardrobe malfunctions—before it reaches viewers or listeners


Virtualdelay uses miniaudio for input/output
